# 📱 User Guide - Installing & Using the Offline App

This guide shows your users how to install and use the app offline.

---

## 🚀 Installation

### iPhone or iPad (iOS)

**Step 1:** Open in Safari
- Use Safari browser (not Chrome or other browsers)
- Go to your website URL

**Step 2:** Tap Share
- Look for the Share button (arrow coming out of a box)
- Usually in the bottom toolbar

**Step 3:** Select "Add to Home Screen"
- Scroll down in the menu if you don't see it
- Tap "Add to Home Screen"

**Step 4:** Confirm
- Edit the name if you want (e.g., "IHRR Expeditions")
- Tap "Add"

**Step 5:** Find Your App
- Look on your home screen
- You'll see a new icon like your website logo
- Tap it to open the app in fullscreen!

✅ **Done!** Your app is now installed and works offline.

---

### Android Phone (Chrome)

**Step 1:** Open in Chrome
- Use Google Chrome browser
- Go to your website URL

**Step 2:** Tap Menu
- Look for the three vertical dots (⋮)
- Usually in the top right corner
- Tap to open the menu

**Step 3:** Select "Install app"
- Look for "Install app" or "Add to Home Screen"
- Tap it

**Step 4:** Confirm
- A popup will ask to confirm
- Tap "Install"

**Step 5:** Find Your App
- Look on your home screen or in your app drawer
- You'll see a new app icon
- Tap it to open the app!

✅ **Done!** Your app is now installed and works offline.

---

### Windows or Mac (Desktop)

**Step 1:** Open in Chrome or Edge
- Use Google Chrome or Microsoft Edge
- Go to your website URL

**Step 2:** Look for Install Icon
- Watch the address bar (top of browser)
- You should see an install icon (⬇️ or similar)
- Click on it

**Step 3:** Confirm Installation
- A popup will appear asking to install
- Click "Install"

**Step 4:** Open the App
- A new window opens with the app
- It looks like a regular app, not a browser

✅ **Done!** Your app is now installed and works offline.

## 📍 What You Can Do Offline

Once installed, you can use these features **without internet:**

✅ **View all locations** - Kathmandu, Pokhara, Mustang, etc.  
✅ **Read itineraries** - All route briefings and descriptions  
✅ **View maps** - Interactive location maps  
✅ **Look at photos** - All location images

✅ **Check your notes** - All notes you've written

❌ **Cannot do offline:**

## 🔄 Using Offline

### Before Going Offline

**Prepare by:**
1. Opening all locations you want to access
2. Opening all documents you want to read
3. Making sure you have good WiFi signal
4. Waiting for images to fully load

This ensures everything is cached and ready to use.

### When You Go Offline

**What you'll see:**
- 📡 Yellow banner at the top says "You're offline"
- Previously visited pages still work
- Cached documents still open
- Photos still display

**What happens if you click a link to a page you haven't visited:**
- You'll see an offline page
- It shows what's available offline
- You can go back to a cached page

### When You Go Back Online

**Automatically:**
- Yellow offline banner disappears
- Fresh content loads from the server
- Your notes and edits sync
- New pages become accessible

## 💡 Tips for Best Results

### 1. Pre-Cache Before Field Work
```
Before you go to the field:
✓ Open the app on WiFi
✓ Visit all location pages you'll need
✓ Open documents you want to reference
✓ Let all images fully load
✓ Turn off and back on WiFi to test
```

### 2. Keep WiFi Available
```
While using offline:
✓ Make sure you have good WiFi during setup
✓ Cache takes 5-10 minutes to build up
✓ Leave the app open while on WiFi initially
✓ Visiting more pages = more cached content
```

### 3. Storage Space
```
Your device needs:
✓ At least 50MB free space
✓ Modern phones have plenty!
✓ Cache automatically expires after 30 days
✓ You can clear cache in settings if needed
```

### 4. Battery Life
```
Using offline actually saves:
✓ Battery - No WiFi/data searching
✓ Data - No downloading from internet
✓ Time - Cached pages load instantly
✓ Money - No data charges!
```

## ❓ Common Questions

**Q: Will my notes save offline?**
A: Yes! Notes saved to your device automatically sync when you're online again.

**Q: How much space does it use?**
A: Typically 20-50MB depending on what you've viewed. Your phone has plenty!

**Q: Can I clear the offline content?**
A: Yes. Go to Settings > Storage/Site Data and find the app's cached data.

**Q: Will it work without WiFi after I've used it?**
A: Yes! Everything you viewed is saved. No WiFi needed.

**Q: Can I share this with my team?**
A: Yes! Everyone can install it on their phone. Content syncs when online.

**Q: What if the app crashes?**
A: Your data is saved locally. Just restart the app.

**Q: How do I update the app?**
A: The app checks for updates automatically. You'll get a notification when available.

**Q: Can I use it in airplane mode?**
A: Yes! Perfect for airplanes and remote areas.

## 🆘 Troubleshooting

### App Won't Install

**iPhone:**
- [ ] Are you using Safari? (Not Chrome)
- [ ] Is the website fully loaded?
- [ ] Try closing Safari and reopening it
- [ ] Try a different WiFi network

**Android:**
- [ ] Are you using Chrome? (Not Firefox)
- [ ] Is the website fully loaded?
- [ ] Try tapping the menu again and looking for "Add to Home Screen"
- [ ] Update Chrome to the latest version

**Desktop:**
- [ ] Is there an install icon in the address bar?
- [ ] Try refreshing the page
- [ ] Update your browser to the latest version

### Offline Mode Doesn't Work

- [ ] Is the app installed? (Using shortcut won't work)
- [ ] Did you use the app while online first? (Needs to cache content)
- [ ] Visit a few pages while online to build cache
- [ ] Try turning WiFi off and back on
- [ ] Check that the yellow offline banner appears

### Documents Won't Load Offline

- [ ] Did you open the document while online?
- [ ] Documents need to be viewed once to be cached
- [ ] Open the document while on WiFi first
- [ ] Wait for it to fully load before going offline

### Yellow Banner Won't Go Away

- [ ] Turn WiFi off and on
- [ ] Close the app completely and reopen
- [ ] Try hard refresh (Ctrl+Shift+R or Cmd+Shift+R)
- [ ] Clear browser cache in settings

### Photos Not Loading

- [ ] Make sure WiFi is on when visiting for first time
- [ ] Wait for photos to fully load before going offline
- [ ] Try closing and reopening the app
- [ ] Check that you have storage space on your device

## 🎓 How It Works (Technical)

**Don't need to know this, but curious?**

- The app uses "Service Workers" - tiny programs that cache content
- As you browse, pages and images are saved to your device
- When you go offline, the Service Worker serves cached content
- Everything is encrypted and stored locally on your device
- You can clear it anytime in your browser settings
- It's the same technology used by Google Maps and Spotify
